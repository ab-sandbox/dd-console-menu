## Console Menu

A simple command-line application written in JavaScript.

### Features

- **Ticket Office** — calculates ticket prices and the number of affordable tickets.
- **Order Delivery** — calculates delivery costs based on distance and order total.
- **Staircase** — prints staircase steps with predefined constraints.

### Requirements

- Node.js

### Run

```bash
node homework-1.js
```

No external dependencies required.
